# Синтетические данные ResponseFlow

Все названия, люди, сообщения и обстоятельства вымышлены. Набор предназначен
только для учебных работ и не содержит сведений реальных клиентов.

## Фиксированные условия

- основная рабочая область: `north`;
- отдельная область для проверки изоляции: `south`;
- время анализа: `2026-09-15T15:00:00+03:00`;
- часовой пояс: Москва;
- рабочее время: понедельник–пятница, 09:00–18:00;
- строки JSONL являются независимыми объектами JSON.

## Состав

- `catalog/participants.json` — участники и их роли;
- `catalog/projects.json` — клиенты, проекты и связь с беседами;
- `messages/messages.jsonl` — 43 исходные записи;
- `messages/revisions.jsonl` — новая редакция одного обещания;
- `messages/new-evidence.jsonl` — новое основание для переоткрытия;
- `documents/` — короткие проектные правила;
- `policies/` — сроки ответа, фразы дат, приоритеты и пороги качества;
- `analyzer/fake-results.json` — воспроизводимые ответы смыслового анализатора;
- `analyzer/fake-llm-responses.json` — правильные и ошибочные ответы поставщика
  LLM для проверок без сети;
- `prompts/system-prompt-v1.md` — версия системной инструкции для LLM;
- `expected/` — эталонные кандидаты и их обновления;
- `inbox/seed.json` — готовая очередь для работы 09;
- `evals/` — эталоны и два варианта результатов для работы 10;
- `invalid/` — намеренно повреждённые примеры.

## Важные сценарии

- `conv-n-001`: исправленная смета обещана, но не отправлена; позднее клиент
  повторяет вопрос;
- `conv-n-002`: клиент недоволен качеством, но сотрудник ответил;
- `conv-n-003`: обещание ещё не просрочено;
- `conv-n-004`: обещание выполнено;
- `conv-n-005`: запрос УПД;
- `conv-n-006`: свежее обращение ещё внутри срока ответа;
- `conv-n-007`: угроза остановить работы, нужно внимание руководителя;
- `conv-n-008`: нейтральная реплика с низкой уверенностью анализатора;
- `conv-s-001`: отдельная рабочая область, данные которой нельзя показывать в
  запросах области `north`.

Файл `messages/messages.jsonl` намеренно содержит сообщение из будущего
`n-001-013`. Оно нужно для проверки отсечения по времени анализа.

## Проверка синтаксиса

Из корня набора можно выполнить:

```bash
python -m json.tool catalog/participants.json >/dev/null
python -m json.tool catalog/projects.json >/dev/null
python -m json.tool analyzer/fake-results.json >/dev/null
```

Все JSONL-файлы, кроме `invalid/malformed-messages.jsonl`, должны читаться
построчно стандартным модулем `json`.
